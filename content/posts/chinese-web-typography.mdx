把一段中文放进默认的网页样式里，它读起来总是有点挤。原因不是字体不好看，而是**西文的排版默认值对中文不成立**。

西文里单词之间有空格，视觉上有天然的呼吸感。中文没有——字与字紧挨着排列，整个段落会变成一块密度均匀的灰。所以西文里刚好的行高，放到中文里就偏紧了。

## 一套可以直接抄的数值

```css
.prose {
  font-size: 16.5px;
  line-height: 1.85;
  letter-spacing: 0.015em;
  max-width: 720px;
}
```

逐个说：

- **行高 1.85**。西文常用的 1.5 在中文里会让行与行粘连。中文正文行高建议 1.7 起步，长文可以到 1.9。
- **字距 0.015em**。给每个字之间加一点点缝。这个值很微妙，加多了会散，加少了等于没加。0.01em 到 0.02em 是好用区间。
- **行宽 720px**。换算过来一行大约 34 个中文字。中文的单行舒适区比西文窄，超过 40 字眼睛回行会开始找不到位置。

## 段间距比段落缩进更好用

中文出版传统是首行缩进两格。但在屏幕上，尤其是长短段落混排的时候，**段间距**比缩进更容易扫读。

```css
.prose p + p {
  margin-top: 24px;
}
```

如果一定要用缩进，那就别再加段间距——两个一起用会让页面变得很松散。

## 标题的呼吸感来自上方留白

一条常见的错误是让标题的上下留白差不多。这样标题会「浮」在两段中间，读者分不清它属于上一段还是下一段。

正确的做法是上大下小：

```css
.prose h2 {
  margin-top: 64px;
  margin-bottom: 0;
  padding-top: 32px;
  border-top: 1px solid rgba(0, 0, 0, 0.1);
}
```

上方大留白把它和上一节切开，下方紧贴正文表示「以下归我管」。那条细线是额外的加强——它让章节边界变成一条可以扫到的水平线。

<Callout type="note" title="一个立刻能用的自检方法">
把浏览器窗口缩到很窄，快速上下滚动。如果眼晕、找不到段落起点，说明行高或段间距不够；如果一片一片的全是空白，说明过头了。
</Callout>

## 别忽略中西文混排

中文段落里夹英文单词和数字是常态，这时候有两个细节值得处理：

- **数字用等宽**。`font-variant-numeric: tabular-nums` 能让数据对齐，表格里尤其明显。
- **拉丁部分单独指定字体**。中文黑体的拉丁字母质量参差不齐，配一套好的拉丁字体（比如 Public Sans、Inter Tight 这类）会让整段文字精致不少。

```css
:root {
  --font-sans: "Public Sans", "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

浏览器会自动为每个字符挑选字体栈里第一个能渲染它的字体。所以把拉丁字体放在前面、中文字体放在后面，混排就自动处理好了。

---

最后说句实话：这些数值不是定律，是起点。真正重要的是**意识到中文排版需要单独设定**——大多数中文网页难读，不是因为审美差，是因为没人调过。
