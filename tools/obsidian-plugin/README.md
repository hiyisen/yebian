# 博客发布（Obsidian 插件）

给 Obsidian 左侧栏加一个火箭图标：点一下，等于在博客仓库里执行 `npm run publish`
（同步 → 构建校验 → 提交 → 推送）。构建不通过就中止，不会把坏内容推上线上。

```
tools/obsidian-plugin/     ← 源码（这里才是唯一需要维护的副本）
        ↓  npm run plugin
<vault>/.obsidian/plugins/blog-publisher/    ← Obsidian 实际加载的副本
```

**改这里的代码，然后跑 `npm run plugin` 装进 vault**；不要直接改 vault 里那份，
不然两边会不一致（`npm run plugin` 只单向复制，而且会覆盖 vault 里的副本）。

## 装 / 更新

```bash
npm run plugin
```

装完**重启 Obsidian**（插件是启动时加载的）。图标没出现的话，去
设置 → 第三方插件 里打开「博客发布」。

## 怎么用

| 动作 | 入口 | 说明 |
| --- | --- | --- |
| 发布博客 | 左侧栏火箭图标，或 ⌘⇧P | 同步 → 构建校验 → 提交 → 推送 |
| 仅同步 | 命令面板「仅同步文章」 | 只把 vault 的文章搬进仓库，不提交 |
| 本地预览 | ⌘⇧L | 起 `npm run dev`，几秒后自动打开 localhost:3000 |
| 停止预览 | 命令面板「本地预览：停止」 | 连 next 的子进程一起收掉 |
| 看日志 | 命令面板「查看上次发布日志」 | 上次发布的完整输出 |

底部状态栏会显示进度（`同步 1/4…` → `构建校验 2/4…`）。失败时自动弹出完整日志，
并且提示里只说一句人话（例如 `构建失败，已中止。内容还留在本地…`），不甩堆栈。

## 设置项

在 设置 → 第三方插件 → 博客发布 里：

- **博客仓库路径**：默认指向本仓库的绝对路径。仓库搬家了就改这里。
- **点按钮前先确认**：默认关。开了之后点图标会先问一句，防误触。
- **失败时自动打开日志**：默认开。
- **环境自检**：一键检查仓库路径 / npm / PATH 能不能找到，出问题先点它。

## 为什么用自写插件而不是现成的

试过 `obsidian-shellcommands`（跑命令很强）但它在 0.23 里**不给单条命令加左侧栏图标**，
得再配一个插件才能凑出按钮，而且那个按钮靠"命令名字符串"匹配，改个名就失效。
自己写一个约 450 行的插件，只干这一件事，没有第三方依赖，也不受别人改版本影响。
